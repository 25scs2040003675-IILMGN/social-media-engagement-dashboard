## How to take a Power BI screenshot on Windows

1. Open Power BI Desktop and navigate to the page you want to capture
2. Press **Windows + Shift + S** to open Snipping Tool
3. Drag to select the dashboard area
4. Save the image to this `screenshots/` folder
